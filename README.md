# She Can Foundation Website

## 🌸 Overview

She Can Foundation is a simple and responsive NGO website created using HTML, CSS, and JavaScript. The project aims to spread awareness about women's empowerment, education, leadership, and community development initiatives.

This website was developed as a beginner-friendly web development project while incorporating modern UI features and interactive elements.

---

## 🚀 Features

* Responsive Design
* Modern Navigation Bar
* Hero Section with Background Image
* About Us Section
* Impact Statistics Section
* Interactive Image Hover Effects
* Contact Form
* Dark Mode Toggle
* Smooth Scrolling Navigation
* Fade-in Animations
* Back-to-Top Button
* Professional Footer

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
